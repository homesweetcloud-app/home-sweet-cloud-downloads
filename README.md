# Home Sweet Cloud: descargas

Tu nube privada en casa. Respalda fotos y videos de Android en tu computadora
Windows y gestiona tus recuerdos despues, con calma.

Este repositorio contiene las descargas de Windows y la guia de instalacion.
El codigo fuente y las llaves de firma no forman parte de este repositorio.

## Version de prueba

- [Descargar para Windows 10/11 de 64 bits](https://github.com/homesweetcloud-app/home-sweet-cloud-downloads/releases/download/v0.1.0-rc3/HomeSweetCloud-Windows-0.1.0-rc3.exe)
- [Ver la version y sus archivos de verificacion](https://github.com/homesweetcloud-app/home-sweet-cloud-downloads/releases/tag/v0.1.0-rc3)
- [Guia de instalacion y vinculacion](LEEME.md)

Home Sweet Cloud requiere la app complementaria Android. El enlace de Google
Play se agregara cuando este disponible la prueba cerrada; descargar Windows
por si solo no habilita el respaldo del telefono.

El instalador de prueba no tiene firma digital de editor. Windows puede
mostrar una advertencia. Comprueba su origen y el hash publicado antes de
ejecutarlo si tienes dudas.
